Zero-Trust & Client-Side Privacy

Privacy Policy for AgentSentinel

Last updated: November 18, 2026

AgentSentinel ("we", "our", or "us") provides autonomous AI agent security tooling, GitHub Apps, and GitHub Actions. We are committed to absolute data privacy and transparency.

1. Zero Telemetry & Local Execution Principle

AgentSentinel is architected from the ground up on a Zero-Trust, Zero-Telemetry model:

  • No Source Code Transmission: Your repository code, pull requests, file contents, and commit diffs are analyzed strictly within your GitHub Actions runner or local execution container. Zero source code is transmitted to or stored on our servers.
  • No Environment Secret Access: AgentSentinel does not read, intercept, store, or transmit your API keys, private credentials, or environment secrets.
  • Local AST Parsing: All Abstract Syntax Tree (AST) validation and command checks occur in ephemeral memory during the runner lifecycle and are destroyed upon process termination.

2. Information We Receive

When you interact with AgentSentinel via GitHub Marketplace or our website:

  • GitHub Installation Metadata: When installed as a GitHub App, GitHub delivers standard webhook identifiers (installation ID, repository name, sender username) to authorize the integration.
  • Support Inquiries: If you contact us for technical support, we receive your provided contact email address solely to reply to your inquiry.

3. Data Retention & Third Parties

We do not sell, rent, monetize, or share your data with any third parties or advertising networks. We do not use third-party tracking cookies or behavioral trackers.

4. Security Controls

All communication between your GitHub runner, website services, and APIs is secured using modern TLS 1.3 encryption. We maintain strict compliance with the Principle of Least Privilege.
